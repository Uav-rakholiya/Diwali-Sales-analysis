Diwali Sales Analysis 

A complete data analysis project focused on understanding customer purchasing behavior during Diwali sales using Python. This project includes data cleaning, visualization, statistical analysis, and machine learning techniques to discover meaningful business insights from sales data.

## Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Outlier Detection
- Sales & Profit Analysis
- Data Visualization using Matplotlib & Seaborn
- Linear & Logistic Regression Models
- Model Evaluation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Goal
The main goal of this project is to analyze festive season sales trends, understand customer behavior, and build predictive models that help improve business decision-making.
